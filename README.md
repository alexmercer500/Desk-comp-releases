# Desk Companion releases

Windows installer and Android app downloads for Desk Companion, plus the small files
(`latest.json`, `android.json`) that the apps check to find new versions.

- **Windows:** download `DeskCompanion_<version>_x64-setup.exe` from the latest release. Not code-signed
  yet, so Windows may warn: choose More info, then Run anyway.
- **Android:** download `DeskCompanion-Android-<version>.apk` and open it on the phone. Allow installs
  from your browser or file manager when Android asks.

Installed copies check for updates themselves and install them after you confirm.
See the latest release for what changed.
